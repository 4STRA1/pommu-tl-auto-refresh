# pommu-tl-auto-refresh

Pommu(`https://ch.dlsite.com/pommu/`)のタイムラインを、一定時間おきに自動で確認・更新する Tampermonkey ユーザースクリプトです。

## 機能

- 設定画面の「アカウント」の下に **「タイムラインの自動更新」** 項目を追加します。
  - 自動更新の有効/無効と、更新間隔(秒)を設定できます。
- 設定した間隔で、タイムライン(TL)の最新投稿を確認します。
- **TLの最上部にいるとき**: 新着があればページを再読込して反映します。
- **TLを遡っているとき**: スクロール位置は動かさず、画面上部に「↑ 新着 N件(タップで最上部へ)」のオーバーレイを表示します。
  - 新着が増えると、件数は加算されます。
  - 最新側の30件をすべて新着と判定した場合は「30+件」と表示します。
  - オーバーレイをタップすると、最上部へスクロールしてから更新を反映します。
- 設定ウィンドウはサイトのライト/ダークテーマに合わせて表示されます。
- 設定ウィンドウの「診断」ボタンで、動作状況を確認・コピーできます。

## インストール

1. [Tampermonkey](https://www.tampermonkey.net/) をブラウザに入れます。
2. 次のリンクを開き、インストールします。

   https://raw.githubusercontent.com/4STRA1/pommu-tl-auto-refresh/main/pommu-tl-auto-refresh.user.js

## 使い方

1. Pommuの設定画面(`/pommu/settings`)を開き、「タイムラインの自動更新」をタップします。
2. 「自動更新を有効にする」にチェックを入れ、更新間隔(秒)を入力して保存します。
   - 初期値は60秒、下限は20秒です。
3. **初回だけ**、TLを開いて少しスクロールしてください。TLの取得先が自動で記録されます。次回以降は、再読込後にスクロールしなくても動作します。

## 仕組み

1. サイト自身の通信(fetch / XHR)を監視し、TLの取得リクエストを学習します。
2. TLは「カーソル式」のページ送りです。スクロールで読み込まれる2ページ目以降のURLから、最新側(先頭ページ)のURLを推定して `localStorage` に保存します。
3. 先頭ページを取得して、その時点の投稿IDを「表示済み」の基準にします。
4. 以降は、設定した間隔で先頭ページを取得します。基準に無い投稿IDを新着として数えます。
5. 基準は、サイトがTLを再取得したとき、または再読込したときに更新されます。

## サーバーへの負荷

- 1回の確認は、TLの最新30件を取得する GET リクエスト1本です。通常のスクロール時の読み込みと同種のリクエストです。
- 送信するのは、機能が有効で、タブが表示中で、設定画面以外のページにいるときだけです。
- 確認のたびにブラウザのキャッシュは使いません。
- 再読込は30秒以上の間隔を空けて行います。
- 間隔を短くするほど、リクエストは増えます。必要以上に短くしないでください。

## 診断

動作しないときは、設定ウィンドウの「診断」を押してください。次の内容が表示され、クリップボードにコピーされます。

- 検出したAPI候補と、表示済みIDの基準の有無
- 保存済みの先頭ページURL
- 投稿リスト以外のAPI(種別と回数)
- 直近のポーリング結果

Issue を立てるときは、この内容を貼ってください。

## 既知の制限

- Pommuの仕様変更(API、画面構造)で動作しなくなる場合があります。
- 基準は取得した時点のものです。ページを開いてから基準を取るまでの間に増えた投稿は、新着として数えません。
- 新着として数えた投稿があとで削除された場合、その分だけ件数が減ります。
- 新着の反映は、ページの再読込で行います。
